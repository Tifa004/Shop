# Shopify Clone Project

A simple **e-commerce web app** built with **React** that demonstrates a Shopify-like shopping experience. Users can browse products, select quantities, add items to the cart, and view the cart contents with a live total. The project is fully responsive for desktop, tablet, and mobile devices.

---

## **Features**

- Home page with a hero section and a "Shop Now" button
- Product shop page:
  - Fetches products from [Fake Store API](https://fakestoreapi.com/)
  - Displays product images, titles, prices, and quantity input
  - Add-to-cart functionality
- Cart page:
  - Shows items added to the cart
  - Update or remove items
  - Shows total number of items
- Navbar and Footer components present across all pages
- Fully responsive design using CSS flexbox and media queries

---

## **Technologies Used**

- **React** (functional components and hooks)
- **React Router** (for routing between pages)
- **CSS** (flexbox, media queries, responsive design)
- **Fake Store API** (product data)
- **JavaScript ES6+**
